# NovaCare Health Services – ISO 27001 ISMS Implementation

**Framework:** ISO/IEC 27001:2022  
**Project:** Information Security Management System (ISMS)  
**Organisation:** NovaCare Health Services – Healthcare Sector

## Project Overview

This project develops a risk-based Information Security Management System for NovaCare Health Services, a healthcare provider operating three outpatient clinics in Ghana.

The assessment evaluates the organisation's information security governance, identifies gaps against ISO/IEC 27001:2022 and establishes a roadmap towards certification readiness.

## Key Assessment Findings

The assessment identified significant weaknesses, including:

- No formally approved ISMS scope or integrated governance framework.
- Incomplete asset inventory, classification and ownership.
- Weak access management and privileged-account controls.
- Inconsistent security awareness and training.
- Inadequate supplier and cloud security assurance.
- No formal incident management process.
- Weak vulnerability, configuration and network security management.
- Insufficient logging, monitoring and data protection controls.
- Limited evidence of internal audit, management review and continual improvement.

## Key Deliverables

1. **ISMS Scope Statement** – Defined organisational, technological and physical boundaries.
2. **Gap Analysis** – Assessment against ISO 27001 clauses 4–10 and Annex A.
3. **Risk Assessment** – Risk register, prioritisation and treatment recommendations.
4. **Statement of Applicability (SoA)** – Applicability and implementation assessment of all 93 Annex A controls.
5. **Internal Audit Checklist** – Audit criteria and finding classification.
6. **PDCA Improvement Plan** – A 20-week implementation and certification-readiness roadmap.
7. **KPI/KRI Framework** – Measures for monitoring ISMS performance and control effectiveness.

## Priority Recommendations

- Establish formal information security governance and approved policies.
- Implement asset ownership, classification and access controls.
- Strengthen MFA, endpoint protection, patching and vulnerability management.
- Improve supplier risk management and cloud security assurance.
- Establish incident response, backup and disaster recovery processes.
- Implement centralised logging, monitoring and security testing.
- Conduct internal audits, management reviews and corrective actions.

## Expected Outcomes

The proposed improvements will help NovaCare strengthen patient information protection, reduce operational and cyber risks, improve regulatory compliance and establish an auditable ISMS aligned with ISO/IEC 27001:2022.
